# 🎵 Mood to Music

A web application that recommends music based on the user's mood. The application allows users to select or enter their current mood and receive suitable music recommendations for that emotion.

## 📌 About the Project

**Mood to Music** is a mood-based music recommendation application designed to make music discovery more personalized.

The application connects a user's emotional state with music recommendations, helping users find songs that match how they feel.

## ✨ Features

* 🎭 Mood-based music recommendations
* 🎵 Personalized song suggestions
* 💻 Simple and user-friendly web interface
* ⚡ Fast and lightweight application
* 📱 Easy to use and navigate
* 🎶 Designed for different moods and emotions

## 🚀 How to Run the Project

### 1. Clone the repository

```bash
git clone https://github.com/joshikalogeswaran23/mood-to-music.git
```

### 2. Open the project folder

```bash
cd mood-to-music
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the virtual environment

**Windows PowerShell:**

```powershell
venv\Scripts\Activate.ps1
```

### 5. Install the required dependencies

If a `requirements.txt` file is available:

```bash
pip install -r requirements.txt
```

Otherwise, install Flask:

```bash
pip install flask
```

### 6. Run the application

```bash
python app.py
```

### 7. Open the application

After starting the server, open the local URL shown in the terminal, usually:

```text
http://127.0.0.1:5000
```

## 🎯 How It Works

```text
User
  ↓
Selects / Enters Mood
  ↓
Application Processes Mood
  ↓
Matching Music is Selected
  ↓
Music Recommendations Displayed
```
