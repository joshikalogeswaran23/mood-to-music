# 🎵 MoodLens AI

### 🧠 Emotion-Aware Music Recommendation System

An AI-powered web application that understands the user's emotions and recommends music based on how they feel and how they want to feel.

The application analyzes natural-language input, detects the user's current emotion, allows them to choose a desired mood, and provides personalized music recommendations.

## 📌 About the Project

**MoodLens AI** is an emotion-aware music recommendation application designed to make music discovery more personalized and meaningful.

Instead of simply asking users to select a mood, MoodLens AI understands their emotions using Artificial Intelligence and creates an interactive **Mood Journey**.

```text
🧠 Current Emotion
        ↓
🎯 Desired Mood
        ↓
🎵 Personalized Music
        ↓
❤️ User Feedback
        ↓
📊 Mood Journey
